LedgerFlow

A real-time payment processing & reconciliation engine: a double-entry PostgreSQL ledger with Redis SETNX idempotency and a Kafka-driven chargeback state machine with Airflow auto-escalation.

Result: processed 50K+ transactions at 508 req/s, p99 = 31 ms, with 56 tests and 0 failures; reconciliation ETL caught 100% of injected discrepancies across 100K transactions.

  • PostgreSQL
  • Kafka
  • Redis
  • Airflow

EquityPulse

A real-time fintech risk & portfolio engine streaming live NYSE/NASDAQ tick data through an LZ4-compressed Kafka pipeline into TimescaleDB and a Redis ring buffer, served via FastAPI.

Result: <200 ms tick-to-dashboard latency and ~0.1 ms reads; VaR, Sharpe, Sortino and a SciPy efficient-frontier optimizer over 10,000 Monte Carlo simulations.

  • FastAPI
  • Kafka
  • TimescaleDB
  • NumPy / SciPy
GitHub ↗

Transportation Crash Prediction

ML risk modeling with Columbia University and the U.S. Dept. of Transportation — geospatial features engineered from 1.2M NYC crash records, benchmarking XGBoost vs. Random Forest and Logistic Regression.

Result: XGBoost maximized F1 with SHAP attribution flagging driver inattention; findings delivered to U.S. DOT covering 47 high-risk intersections.

  • XGBoost
  • GeoPandas
  • PostGIS
  • SHAP
